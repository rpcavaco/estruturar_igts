
# Estruturar IGTs

## Execução

1. Criar pastas de município (se não existir já) e de versão em 'dados'
2. 'Copiar texto' do site DRE e colocar no ficheiro 'aviso_publicacao.txt' numa pasta 'regl' dentro da pasta criada em 1.
3. Executar 'processar_regulamento.py', alterando a configuração em 'main'.
3. Executar 'extrair_referentes_regulamento.py', alterando a configuração em 'main'.
